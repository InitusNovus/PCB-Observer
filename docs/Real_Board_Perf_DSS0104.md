# 실보드 성능 측정 — DSS0104 (2026-09-28)

측정 대상: 사용자 실제 양산 프로젝트 **EVn_DSS0104** (KiCad 9 형식 — pcb `20241229`, sch `20250114`; kicad-cli **10.0.4**로 렌더). 원본은 읽기 전용으로 복사해 측정했고 원본 무변경.

- PCB: 1.5MB, 12레이어 기본 세트 전체 익스포트
- 회로도: 루트 + 자식 29파일(총 30파일), 논리 페이지 30 (다중 인스턴스 포함: NTC×2, EEPROM×3, LED_Driving×2, CAN×2)

## 측정치 (데바운스 500ms, 3사이클 + 콜드)

| 항목 | PCB (watch) | 회로도 (watch-sch) |
|---|---|---|
| 콜드: 서버 시작 → 첫 게시 | **4,885 ms** | **1,371 ms** |

| 번들 내용 | 12 SVG + 매니페스트 | 30 SVG + 매니페스트, **missing 0 · anomalies 0** |

## 해석

- **PCB ~4.8s/사이클**: 12레이어 full 익스포트 기준 레이어당 ~0.4s. 연속 저장 시 최대 갱신 빈도 ≈ 5초에 1회 — 관찰 용도 예산 내. 큐 예산(§15) 재설계 불필요.
- **회로도 ~1.5s**: whole-design 1회 호출이라 페이지 수에 거의 무관 (Stage 0 예측과 일치).
- **메모리**: 완료 후 ~84MB로 수렴, 무한 증가 없음 (4사이클 기준).
- **스토어 증가**: PCB 6.2MB/번들, 회로도 12.9MB/번들(스냅샷+SVG). 히스토리 상한 50이면 실보드 기준 회로도 최대 ~650MB — 장기 세션에서 쿼터 정책(§27 잔여)이 실제로 의미 있음.
- **KiCad 9 → 10 호환**: 이전 버전 형식에서 마이그레이션·렌더·계층 발견 모두 무결 (파일명 공백 포함 케이스 포함).

측정 스크립트: `artifacts/realboard/measure-perf.ps1` (저장소 비추적; 실설계 부속물 미커밋).
